Plain-language privacy information for this independent fan project. Last updated 12 October 2026.

Who runs this site

APEX Race Culture is a fan-made demonstration website. The site owner/operator has not yet added a public legal name or contact address. Add those details before opening this service to the public or collecting real subscribers.

What this version stores

  • Broadcast settings: the session label, approved embed URL, status, and update time, stored by the server in data/site.json.
  • Reaction game: the display name and best reaction score you submit, stored in the same server data file.
  • Newsletter: your email address and signup time, only after you submit the signup form and tick its consent box. The admin panel can view and export this list.
  • Admin session: an eight-hour, HttpOnly, same-site cookie. The login password is provided to the server operator through an environment variable and is not saved in the database.

The server does not intentionally send these entries to an analytics or advertising service. The site requests public session schedules, classifications and championship data from OpenF1. Those requests are normally made by this site server; if the server cannot reach OpenF1, your browser may request the same public schedule directly, in which case OpenF1 receives your connection information. OpenF1 applies its own policies and this site does not send your reaction score or newsletter email to it. Your browser also connects to Google Fonts and to the video provider if a live embed is enabled; those providers receive their usual connection information and apply their own policies.

How long data remains

Broadcast settings remain until changed or cleared by an admin. Newsletter addresses and reaction scores remain in the site data file until the operator removes them. You can remove a newsletter signup using the form below. There is no automated unsubscribe email in this prototype.

Your choices and requests

Use the unsubscribe form above to remove an email address from this site's list. For other requests about data or for questions, contact the site operator through the contact method added by the owner when the site is launched. Do not enter sensitive personal information in the reaction game.

Security and public deployment

This prototype stores data in a JSON file on the server. Before a public launch, the operator should configure HTTPS, backups, access controls and a production database, publish an accountable privacy contact, confirm retention periods, and assess applicable privacy and direct-marketing requirements for every region served. The website does not promise a specific legal compliance status.
