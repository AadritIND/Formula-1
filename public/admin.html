      RACE CONTROL
      SERVER STATUS

      PERSISTENT BY DESIGN.

      Changes are written to the private data/site.json file. The first-run password is stored only as a salted scrypt hash. Newsletter exports contain personal information; keep them private.

      LIVE CHAT

      KEEP THE PADDOCK CLEAN.

      Messages are accepted only while a broadcast session is on air (the same live state the timing tower uses). Deleting a line removes it for every viewer on the next poll.

      TEAM RADIO

      PUT THE PIT WALL
      IN WORDS.

      The live page transcribes team radio with Groq Whisper as calls arrive, one at a time, and keeps the text beside the timing tower. The recordings are Formula 1's copyright and F1's terms restrict copying them, so check before publishing transcripts; the audio itself is never relayed through this server, only linked back to the F1-hosted recording.
